## How to use it
1. Click the link above. It opens in any browser, on a phone or a laptop. No login and no code needed.
2. Fill in your details. The boarding pass updates as you type.
3. Click **Stamp my ticket** to see your survival chance.
4. Click **Download ticket** to save your boarding pass as an image.

## About the project
- **Task:** CodSoft Data Science Internship, Task 1
- **Goal:** predict whether a Titanic passenger survived
- **Data:** 891 real passengers
- **Features I built:** passenger title, family size, travelling alone, has cabin
- **Models compared:** Logistic Regression, Random Forest, Gradient Boosting
- **Accuracy:** about 82-83%
- **Extras:** SHAP explanations, and the model runs fully in the browser 

## Files

- index.html: the web page
- titanic_model.js: the trained model used by the web page
- train.csv, test.csv: dataset
